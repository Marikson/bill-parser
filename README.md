# bill-parser
Python script which parses .pdf bills and extracts the final prices to be paid and creates a summary .txt file.

It requires all the .pdf files in one folder with the given names:
    - common_cost*.pdf
    - cold_water*.pdf
    - electricity*.pdf
    - sewer*.pdf
    - internet*.pdf
    - garbage*.pdf

The parsing is based on predifend fields of the bill.
